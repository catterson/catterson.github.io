Conceptual Power

Practice calculating the probability of Power for the following tests. Hint : you will need to calculate the t-value for each test, and use R to look-up the cut-off scores for the given t-distribution, alpha level, and directional vs. non-directional hypothesis.

  • cut-off value (to compare your slope) : qt(p = 1-α/2, df = n-1)
    • alpha : divided by two for a two-tailed test
    • n : the sample size
    • note : you can calculate the cut-off scores for n = 10, n = 100, and n = 1000 and confirm the values approach 1.96.
  • standard error : pooled sd / sqrt(n)
  • degrees of freedom : n - 1
  • t-value for your slope: b / se
  • probability of a given t-value : pt()

  1. Slope = .43, Pooled SD = 2, Sample Size = 100, α = .05

  2. The sample has more variation (increase the pooled SD) : Slope = .43, Pooled SD = 4, Sample Size = 100, α = .05

  3. The effect is stronger (increase the slope) : Slope = .73, Pooled SD = 4, Sample Size = 100, α = .05

  4. The sample size is larger (increase n) : Slope = .73, Pooled SD = 4, Sample Size = 1000, α = .05

  5. There’s a negative relationship (decrease the slope and also change the cut-off) : Slope = -.20, Pooled SD = 4, Sample Size = 15, α = .05

  6. The researcher has a more conservative test (iecrease the alpha to .01) : Slope = -.20, Pooled SD = 4, Sample Size = 15, α = .01

  7. The researcher does a more liberal test (increase the alpha to .10) : Slope = -.20, Pooled SD = 4, Sample Size = 15, α = .10
